### Hi, I'm Yonatan

I'm based in Haifa, Israel. I build open-source tools with AI agents, MCP and Cloudflare Workers, and I work on Hebrew and right-to-left support in open-source apps.

#### Projects

- **[volunteer-compute-broker](https://github.com/yonatan-langer83/volunteer-compute-broker)**: a broker that lets nonprofit and open-source projects split work into small tasks that volunteers' AI apps (Claude, Gemini CLI and others) claim over MCP and complete. It has a task state machine, one holder per task (tested with concurrent claims), monthly budgets, dependencies, encrypted keys with log redaction, and a public record of finished work. TypeScript, Cloudflare Workers, D1 and Durable Objects. MIT licensed.
- **[volunteer-compute-test](https://github.com/yonatan-langer83/volunteer-compute-test)**: Harbor Pantry, a small Python sample project for a fictional food bank. It's the broker's first test target, with real tasks for volunteer agents to pick up.
